# Release Notes - OpenPDF 3.0.7

This release adds support for reading PDF files larger than 2 GB, fixes an encryption bug that could leave content unencrypted, and makes `PdfReader` and the barcode generators more robust against invalid input.

## ⚠️ Upgrade Notes
* **File offsets are now `long` (PR #1591).** To support files larger than 2 GB, several methods and fields changed from `int` to `long`:
    * `RandomAccessFileOrArray`: `length()`, `getFilePointer()`, `getStartOffset()`, `setStartOffset(long)`
    * `PRTokeniser`: `seek(long)`, `getFilePointer()`, `length()`, `getStartxref()`
    * `PdfReader`: `getLastXref()`, `getEofPos()`, `getFileLength()`, and the protected fields `xref` (`long[]`), `lastXref`, `eofPos` and `objStmToOffset` (`Map<Integer, Long>`)
    * `PRStream`: `getOffset()` and the constructor `PRStream(PdfReader, long)`

  Code that stores these values in an `int` needs a cast, and code compiled against an earlier version must be recompiled.
* **brotli4j is now an optional dependency (PR #1590).** It is no longer pulled in transitively. Projects that read or write Brotli-compressed PDFs must add `com.aayushatharva.brotli4j:brotli4j` themselves.

## 🌟 New Features & Enhancements
* **Large Files:** `PdfReader` can now read PDF files larger than 2 GB. File positions are tracked as 64-bit offsets throughout the read path (PR #1591, fixes #1582).
* **Brotli:** `DecodeParms` are now applied after `/BrotliDecode`, so predictor-encoded Brotli streams are decoded correctly (PR #1674, fixes #1654).
* **Predictors:** The shared predictor decoder now reconstructs TIFF predictor 2 for 1-, 2-, 4-, 8- and 16-bit components. This also applies to `/FlateDecode` and `/LZWDecode` streams (PR #1674).

## 🛠 Bug Fixes
* **Encryption:** `PdfWriter.DO_NOT_ENCRYPT_METADATA` no longer silently switches to embedded-files-only mode, which left all stream and string content unencrypted (PR #1589, fixes #1576).
* **PdfReader:**
    * A corrupt cross-reference stream that points at an object stream outside the document no longer causes an `IndexOutOfBoundsException` (PR #1602, fixes #1601).
    * The PNG Average predictor is now computed from unsigned neighbouring bytes, and the bytes-per-pixel value is rounded up for samples smaller than one byte (PR #1674).
* **Barcodes:** EAN-13, UPC-E and Data Matrix now reject values that would be silently encoded as a different value (PR #1675).
* **Text Extraction:** Fixed a context stack exception in `PdfTextLocator` for PDFs without a context, and improved text measurement and matching (PR #1538).
* **Dependencies:** A transitive brotli4j no longer triggers an `UnsatisfiedLinkError` in libraries that detect it on the classpath, such as Apache HttpClient 5 (PR #1590, fixes #1584).

## 🔒 Security & Dependencies
* **Code Scanning:** Resolved the open code scanning alerts (PR #1678):
    * `MessageDigest` instances are no longer shared as fields in `PdfEncryption` and `PdfSmartCopy`.
    * The `SilentPrintServlet` example no longer writes the request URI into the page.
* **Dependency Updates:**
    * **HTML Parsing:** Updated `neko-htmlunit` from 5.6.0 to 5.7.0.
    * **Maven:** Bumped `maven-compiler-plugin` from 3.15.0 to 3.16.0 and `maven-jar-plugin` from 3.5.0 to 3.5.1.

## 🧹 Maintenance & Refactoring
* **Code Quality:**
    * Refactored classes in `org.openpdf.text` to reduce duplication and improve readability (PR #1672).
    * Removed an unused parameter from `PdfCell.addImage` (PR #1671).
* **Build System:** Updated the GitHub Actions `actions/checkout` to v7 and `actions/setup-java` to v6 (PR #1680).
